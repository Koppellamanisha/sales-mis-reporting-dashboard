# Sales MIS Reporting Dashboard
## Project Overview
This Project is an Excel-based Sales MIS Reporting Dashboard created to analyze sales performance and provide management-level Insights.
## Objective
The objective of this project is to organize sales data, calculate key performance Indicators, analyze salesperson, product and regional
performance, and present the results in a clear MIS reporting format.
## Tools used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data formatting and sorting
- KPI reporting
## Key Performance Indicators
The dashboard includes:
- Total Orders
- Total Net sales
- Quantity Sold
- Average Order Value
## Salesperson Performance
Salesperson performance is analyzed using:
- Total Orders
- Total Net Sales
This helps compare individual salesperson performance.
## Product Performance
Product performance is analyzed using:
- Quantity Sold
- Total Net Sales
This helps identify products with higher sales contribution and demand.
## Region Performance
Regional performance is analyzed using:
- Total Orders
- Total Net Sales
This provides a comparison of sales performance across regions

## Management Insights
The report Provides management-oriented insights based on salesperson, product and regional performance.
